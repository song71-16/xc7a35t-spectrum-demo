## 使用方法

让具备本地文件读取能力的助手读取目标 `SKILL.md`，同时给出仓库、任务、允许的操作和需要核对的证据。支持技能目录的工具可按其自身机制发现该目录；本包不要求安装到系统位置。示例中的 `$技能名` 仅在该工具已发现对应技能时使用。

一次选择与任务相关的技能；逐项输出证据路径、实际判断、不能证明什么。技能是方法，不授予提交、上传、EDA、板卡或网络权限。仓库治理和当前用户决定优先于示例。

原本机项目管理 skill 的历史结构检查、两个纸上场景与本次公开适配版分开记录。公开三技能是此次新整理的版本，没有宣称历史实板/软件测试就是技能自身验证。本次完成 frontmatter、相对链接、附件配对和来源保全的离线核查；既有只读 supervisor 的独立场景与后审结果统一记录在 [本次整理记录](../docs/competition-supplement-2026-11-03.md)。不量化未经测量的效率收益，不把纸上检查称跨机器复现或硬件 PASS。
